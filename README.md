# 🦉 달빛 우체부 — AI로 만드는 어린이 잠자리 동화 시리즈

부엉이 우체부 **뽀랑이**가 잠 못 드는 친구들에게 꿈 편지를 배달하는 잠자리 동화 시리즈입니다.
이 저장소는 동화를 기획하고 AI로 제작해 음원 플랫폼(멜론)에 연재하기까지의 **전 과정**을 기록하고,
그 과정을 그대로 강의 교재로 쓰기 위해 만들었습니다.

## 이 저장소로 할 수 있는 것
- **작품 보기**: 회차별 대본과 제작 기록 (`episodes/`)
- **과정 배우기**: 기획부터 배포까지 단계별 강의 자료 (`lecture/`)
- **직접 만들어 보기**: 템플릿과 프롬프트를 복사해 나만의 동화 시리즈 시작 (`series/`, `prompts/`)

## 폴더 구성
| 폴더 | 내용 |
|---|---|
| `series/` | 시리즈 바이블 — 세계관, 캐릭터, 말투, 반복 구조 |
| `episodes/` | 회차별 기획서·대본·제작 메모 (`ep01/`, `ep02/` …) |
| `prompts/` | 실제로 사용한 AI 프롬프트 모음 (대본, 이미지, 음성) |
| `lecture/` | 강의 목차와 차시별 자료 |
| `process-log/` | 제작 일지 — 무엇을 왜 바꿨는지 |
| `assets/` | 표지·삽화·음성의 **링크와 설명만** 보관 (원본 파일은 드라이브에) |

## 제작 흐름
```
기획(콘셉트) → 시리즈 바이블 → 회차 기획 → 대본 → 수정
        → 음성(TTS/녹음) → 배경음·믹싱 → 표지 → 멜론 등록
```

## 진행 현황
- [x] 시리즈 콘셉트 확정: 달빛 우체부
- [x] 주인공 이름 확정: 뽀랑이 (초안명: 토토)
- [ ] 1화 대본 (목표 분량 약 10분)
- [ ] 1화 음성 제작
- [ ] 1화 표지
- [ ] 멜론 등록

## 이 시리즈를 만든 이유
처음에는 우리 아기에게 주는 선물로 시작했습니다. 수익보다 "아이가 잠들기 전 듣고 싶은 이야기"가 기준입니다.
